# Phase 001 — Scaffold & Design System + Motion Foundation

**Goal:** A running Next.js App Router app with the design-token system, Inter
typography, the motion foundation (Lenis + Framer Motion spring tokens), a
responsive layout shell with sticky minimal nav, and `npm run dev` working.
**End state = show Alex the base before moving to Phase 002.**

Ref: `docs/superpowers/specs/2026-07-16-portfolio-design.md` §2, §3, §4, §6.

## Layers (infra → data → logic → presentation → testing)

### Infra / scaffold
- [ ] `create-next-app` in place: App Router, TypeScript **strict**, Tailwind,
      ESLint, `src/` dir, `@/*` alias. (App scaffolds into repo root; keep
      existing `.planning/`, `content/`, `docs/`, `CLAUDE.md`.)
- [ ] Tailwind v4 (or v3 if smoother) configured; global CSS reset.
- [ ] shadcn/ui initialized (base primitives available; add on demand).
- [ ] Dependencies: `framer-motion`, `lenis`, `gsap`, `ogl`. (MDX deferred to 004.)
- [ ] Inter via `next/font` (variable), SF-like system fallback stack.

### Data / tokens
- [ ] Design tokens: color (monochrome scale + single swappable accent token),
      type scale (display → body), spacing rhythm, radii, shadows, **easing/
      spring curves** — as CSS variables + surfaced in Tailwind theme.
- [ ] Accent isolated to ONE token so monochrome↔accent is a one-line swap.
- [ ] `prefers-reduced-motion` handling wired at the token/util level.

### Logic / motion foundation
- [ ] Lenis provider (client component) wrapping the app; respects reduced-motion.
- [ ] Shared Framer Motion variants/spring presets in `lib/motion.ts`.
- [ ] Reusable primitives: `<Reveal>` (masked/opacity scroll reveal),
      `<MagneticButton>` — thin, reduced-motion aware. (Shader deferred to 002.)

### Presentation / shell
- [ ] Root layout: font vars, base bg/ink, skip-link, semantic landmarks.
- [ ] Sticky minimal top nav: `Work · About · Blog · Contact` + CV button;
      smooth-scroll anchors on `/`, mobile menu. Placeholder section anchors.
- [ ] Footer stub. Placeholder section blocks so scroll/nav is demonstrable.

### Testing / verification
- [ ] `npm run build` passes (TS strict, lint clean).
- [ ] `npm run dev` renders; nav scrolls; reduced-motion path works.
- [ ] Screenshot/描述 the base for Alex before Phase 002.
