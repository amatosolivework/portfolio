# Phase 004 — Blog (MDX)

**Goal:** MDX blog pipeline — post list + post page, one seed technical post
(drafted for Alex's approval), RSS + SEO basics. Ref: spec §5, ROADMAP #4.

## Approach
- Posts as `content/blog/<slug>.mdx` with frontmatter (title, description, date,
  tags). Read via `fs` + `gray-matter`; render with `next-mdx-remote/rsc` (RSC,
  static). Custom MDX components styled to the design system (no extra prose dep).
- Static: `generateStaticParams` + `generateMetadata` per post.

## Tasks
- [ ] Deps: `next-mdx-remote`, `gray-matter`.
- [ ] `lib/blog.ts`: `getAllPosts()` (sorted, newest first), `getPost(slug)`,
      reading-time estimate. Typed frontmatter; skip drafts.
- [ ] `components/mdx/mdx-components.tsx`: h2/h3/p/ul/ol/li/a/blockquote/pre/code/hr
      styled Apple-minimal + Inter, mono for code.
- [ ] Seed post `content/blog/clean-architecture-swiftui.mdx` — technically
      accurate, grounded in WRDB's real architecture. **Draft for Alex to approve/
      edit — no fabricated metrics or events.**
- [ ] `app/blog/page.tsx`: real post list (date, title, description, tags, reading
      time), scroll reveals, mono signature.
- [ ] `app/blog/[slug]/page.tsx`: post header + MDX body, generateStaticParams +
      generateMetadata (OG), back link.
- [ ] SEO basics: `app/blog/rss.xml/route.ts` (RSS), `app/sitemap.ts`,
      `app/robots.ts`.
- [ ] Verify: build clean, prod smoke test (list + post render, RSS 200, sitemap),
      Playwright desktop/mobile, 0 console errors, commit.
